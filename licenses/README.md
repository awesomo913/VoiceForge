# licenses/

Holds the license text for any third-party component vendored as a separate
binary (as opposed to a Python package pulled in via `requirements.txt`,
whose licenses are documented in `THIRD_PARTY.md` instead).

Currently empty: `rubberband-COPYING` (the GPL-2.0 license text) belongs here
once a human vendors the `rubberband` command-line tool per
`vendor/README.md` — copy it verbatim from the exact release that gets
downloaded rather than retyping it from memory, so the text matches whatever
Rubber Band's own project ships with that specific version.
